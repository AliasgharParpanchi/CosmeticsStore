# CosmeticsStore

## توضیحات پروژه
یک فروشگاه آنلاین لوازم آرایشی با قابلیت مدیریت موجودی کالا، دسته‌بندی محصولات و اتصال به صفحه پرداخت. این پروژه با تاکید بر معماری مناسب توسعه یافته تا بتوان بخش داده را جداگانه در پروژه‌های دیگر نیز مورد استفاده قرار داد. همچنین مدیریت کاربران و سطوح دسترسی به صورت کامل پیاده‌سازی شده است.

## تکنولوژی‌ها و ابزارهای استفاده شده
- **ASP.NET MVC**
- **Razor**
- **jQuery**
- **JavaScript**
- **HTML**
- **CSS**
- **Bootstrap**
- **Ajax**
- **Chart.js**
- **Entity Framework**
- **SQL Server**

در این پروژه از معماری لایه‌ای استفاده شده و لایه داده به صورت مستقل طراحی شده است. همچنین الگوی UnitOfWork برای مدیریت تراکنش‌ها و عملیات داده‌ای مورد استفاده قرار گرفته است.

## راه‌اندازی و اجرا
1. پس از کلون کردن پروژه، پکیج‌های مورد نیاز را از طریق NuGet نصب کنید.
2. با استفاده از دستور `migration` دیتابیس مورد نیاز را بسازید.
3. ثبت‌نام کاربر را انجام دهید.
4. برای تبدیل کاربر به ادمین، وارد جدول `Log.Users` در دیتابیس شوید و نوع کاربر را تغییر دهید.
5. پس از تبدیل کاربر به ادمین، می‌توانید کالاها، دسته‌بندی‌ها و سایر موارد مدیریتی را تعریف کنید.
6. برای ثبت سفارش نیز می‌توانید با یک کاربر دیگر وارد شده و عملیات سفارش را انجام دهید.

## نحوه استفاده
- ابتدا یک کاربر تعریف کنید و از طریق دیتابیس (جدول `Log.Users`) آن را به ادمین تبدیل کنید.
- با کاربر ادمین، کالاها و دسته‌بندی‌ها را مدیریت کنید.
- با کاربر معمولی، سفارش‌های جدید ثبت نمایید.
